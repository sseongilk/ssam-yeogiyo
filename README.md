# 쌤! 여기요! (콜벨 팡팡)

대학병원 밤 근무를 버티는 도트 게임. 병동 침대 6개에서 켜지는 콜벨을 톡톡 눌러 끄고, 아침 7시가 되면 퇴근.
간호사들이 가볍게 스트레스를 풀 수 있게 실패 부담은 줄이고, 시원하게 터뜨리는 맛과 꾸미기 모으는 재미를 넣음.

## 실행
- PC 확인: `python tools/build.py` 후 `dist/play.html`을 브라우저로 열기
- 웹 공개용 결과: `docs/index.html` (GitHub Pages)

## 조작
- 아래 카트에서 말풍선이 원하는 물건(수액·진통제·물·담요)을 고른 뒤 그 침대를 누름 (PC는 Q~T로 고르고 숫자 1~6으로 침대)
- 고른 물건은 계속 들고 있어 같은 요청을 연달아 처리 가능, 간호사 머리 위에 표시
- 틀린 물건을 주면 「이거 말고요!」: 콤보·집중 모드 끝, 체력 -3, 콜벨은 남음
- 빨간 말풍선(무리한 요구)은 거절 도장을 들고 세 번 눌러 거절
- 체력 막대 오른쪽 일시정지 버튼(PC는 Esc·P): 계속하기 / 그만하기(이번 기록은 저장 안 함). 다른 앱으로 넘어가면 자동 일시정지
- 진상 보너스는 화면을 마구 연타 (PC는 스페이스), 라운딩은 투약·검사·기록 칸을 누름 (PC는 1·2·3)

## 규칙
- 한 판 135초 = 22:00 → 07:00. 새벽 3~4시가 가장 바쁨 (콜벨이 자주, 빨리 꺼져야 함)
- 점수 = (100 + 빠르기 × 100, 무리한 요구는 300 + 빠르기 × 100) × (1 + 콤보 × 0.05, 20콤보까지) × 집중 모드 2배
- 체력: 1초에 0.7씩 줄고 콜벨을 놓치면 -12. 커피 +30, 간식 +15·+200점. 0이 되면 「기절」로 끝
- 07:00까지 버티면 「퇴근 성공」, 남은 체력 × 10 + 1,000 보너스
- 집중 모드: 15콤보마다 8초 동안 점수 2배, 놓치면 끝
- 진상 보너스(00:30, 04:20쯤): 5초 안에 24번 연타하면 퇴치 +1,000, 연타마다 +20. 진상 3종, 대사 7개 무작위
- 라운딩 타임(02:00, 05:40쯤): 업무 카드 6장을 투약·검사·기록으로 정리, 맞힐 때마다 +150, 모두 맞히면 +500
- 오늘의 근무: 날짜로 정한 같은 순서로 모두 겨룸, 랭킹 「오늘」 탭

## 꾸미기 (누적 점수로 해금, 모두 110개)
- 근무복 11 (줄무늬·하와이안·무지개 포함), 머리색 11 (대머리·무지개 포함)
- 머리 장식 20 (바나나 핀·냄비·링거팩·무지개 아프로 등), 얼굴 15 (코피 휴지·콧수염·피에로 코 등)
- 소품 14 (삼각김밥·왕 주사기·장갑 풍선·메가폰 등), 펫 8 (수액팩 친구·유령·미니 진상 등)
- 병동 테마 6 (기본 민트·핑크 소아·나무 바닥·바닷속·우주 병동·황금 VIP): 게임 화면의 바닥·벽·이불 색
- 휴게실 가구 20 (사직서 액자·컵라면 탑·퇴근 시계·링거 옷걸이 등), 벽지 5. 휴게실에서 가구를 눌러 놓기·치우기
- 잠긴 꾸미기도 ◀ ▶로 입혀 보기(미리 보기) 가능, 실제로 입는 것은 해금된 것만
- 해금 점수는 `src/game.js`의 LOOKS·FURN 값 × NEED_SCALE(3)

## 기록·업적
- 근무·퇴근·기절 횟수, 끈 콜벨, 진상 퇴치, 거절, 커피, 틀린 물건, 라운딩 완벽, 최대 콤보, 오늘의 근무 횟수를 누적
- 업적 22개 (첫 퇴근, 콜벨 만렙, 진상 저승사자, 이거 말고요 장인 등). 시작 화면 「기록」에서 메달을 눌러 내용·진행도 확인
- 기록은 서버 `stats`에도 저장해 복구 코드로 함께 되찾음

## 소리
- 시작 화면 오른쪽 위 스피커: 음악+효과음 → 효과음만 → 끔
- 배경음악은 Web Audio로 직접 연주: 시작 화면(잔잔), 근무(새벽 피크에 빨라짐), 진상 보너스(긴박), 라운딩(경쾌)

## 링크 미리보기·홈 화면에 추가
- `assets/og.png`(1200×630)·아이콘·`manifest.webmanifest`를 빌드 때 `docs/`에 복사, 미리보기 주소는 `tools/build.py`의 SITE
- 시작 화면 「앱 설치」: 안드로이드 크롬은 바로 설치 창, 그 밖에는 홈 화면 추가 방법 안내. 홈 화면에서 열면 버튼 숨김

## 이름·아이디 (기기마다 고정)
- 이름 최대 5글자, 같은 이름 불가(서버에서 대소문자 무시 유일 규칙, 저장 전 확인). 병동 12개 + 무소속 (`WARDS`)
- 기기마다 무작위 id·비밀값·복구 코드(8자리)를 만들어 localStorage·IndexedDB·쿠키 세 군데에 저장, 하나만 남아도 되살림
- 브라우저에 저장소 보존 요청(navigator.storage.persist)
- 이름 화면의 복구 코드를 적어 두면, 저장소가 지워지거나 기기를 바꿔도 「코드로 불러오기」로 같은 기록을 되찾음
- 공용 랭킹에 내 줄이 있으면 이름·누적 점수·꾸미기를 서버에서 되살림

## 랭킹·채팅 (Supabase)
- 불량 판정소와 같은 Supabase 프로젝트, 표 이름 앞에 `nn_` (`tools/supabase.sql`, 여러 번 실행해도 됨)
- 랭킹 탭: 개인 / 병동(병동원 최고 점수 합계) / 오늘. 큰 점수는 44.3k·1.23M처럼 줄여 표시
- 비밀값·복구 코드는 읽을 수 없고, 기록은 `nn_submit` 함수로만 저장. 최고·누적 점수는 내려가지 않음
- 복구는 `nn_restore` 함수 (0.5초 대기로 마구 넣어 보기 방지)
- 채팅: 40자, 기기당 3초에 1번, 최근 100개 보관, 기본 비속어는 * 로 가림
- `supabase.json`에 공개용 url·anon 키 (service_role 키는 넣지 않음). 없으면 이 기기 랭킹으로 동작

## 화면
- 논리 해상도 128×224, 창 크기에 맞춰 꽉 채우고 세로가 긴 휴대폰은 위아래를 배경색으로 늘림
- 글자는 4배로 그린 뒤 픽셀 가운데만 읽어 도트로 찍음

## 구조
- `src/game.js` : 게임 전체, `src/page.html` : 페이지 틀, `tools/build.py` : 글꼴을 잘라 넣고 한 파일로 묶음
- `src/mock.js`, `src/mock.html`, `tools/build_mock.py` : 처음 시안
- `fonts/` : 갈무리 도트 글꼴 (SIL OFL 1.1, `fonts/OFL.md`)

## 화면 확인용
`dist/play.html?shot=이름` (네트워크를 쓰지 않음)
- `play` `fever` `pause` `theme` `rec` `install` `dup` `icon` `karen` `karenwin` `round` `over` `fail` `name` `code` `dress` `lounge` `rank` `ward` `chat` `chattitle` `tut1`~`tut8` `run`
- `auto`: 자동으로 한 판을 끝까지 하고 결과를 페이지 제목에 기록
